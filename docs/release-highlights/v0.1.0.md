Locker Manager now keeps your school's data in one file, safely. You can start a new school file, open one from your shared folder, or try a made-up demo school with 228 lockers. Only one person can change the file at a time and everyone else sees who is editing. Every change saves itself, every save keeps a backup, and if two versions ever exist the app shows you both and keeps the one you do not choose. There are still no locker tasks yet: those arrive next.
