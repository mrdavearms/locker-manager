Locker Manager now guides you through starting a new school year. On Home, Start next year walks through ten steps: print the end-of-year checklist so students reset their own locks to 0 0 0 0 on their last day, record which were reset, archive the year (with a typed confirmation and a backup kept first), optionally move students up a year level, import, make next year's codes, give out lockers, print, and reset any remaining locks. Progress is kept in the file, so anyone can carry on. Keyed lockers now have a key register: key numbers, and keys given out, returned, lost, replaced or charged for.
