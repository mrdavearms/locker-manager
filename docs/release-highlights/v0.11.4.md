**Mac users: install this version by hand, once.** Versions 0.11.0 to 0.11.3 on a Mac update themselves once, then stop. After that, every check shows "Could not check for updates: ENOTEMPTY: directory not empty". This version fixes the fault, but a Mac that already shows the message cannot fetch the fix by itself. Click **Open the download page** on that message, or use the Mac download link above. Then drag Locker Manager into Applications and choose **Replace**. Your school's file is not touched. From then on, updates install themselves again.

Windows computers are not affected and update as usual.
