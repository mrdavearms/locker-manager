Locker Manager can now print locker labels. Choose every locker, one Homeroom, one bank, chosen numbers, changed lockers or spares, see the real sheet before you print, and save a PDF or print it. Long names shrink to fit and then wrap, and any that still do not fit are listed. Measure your own box of labels, print a calibration page to line up each printer, and change the layout by dragging boxes on an enlarged label. Labels print at exact millimetre positions on Windows and Mac.
