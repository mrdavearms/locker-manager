Locker Manager now prints student letters, reports and exports. Each student gets a one-page letter with their locker, their code in boxes, and only the sections that suit their kind of lock; letters waiting on a lock reset are held back, and nothing prints unless every letter fits on one page. Change the letter in Settings, Letters: choose the sections, write the words, add your lock maker's pictures, and add other languages. Reports include group lists for teachers, a CONFIDENTIAL master list, lockers by bank, locks to reset, an end-of-year reset checklist, a sign-off sheet, a key register and changes since a date, each as PDF, print, Excel or CSV. The whole file can be exported to one Excel workbook and turned back into a data file. Letters and anything with codes print only while the file is open for editing, because every printed code is recorded.
