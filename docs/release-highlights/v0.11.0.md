Locker Manager now updates itself on a Mac as well as on Windows. When it opens and finds a new version, it downloads it and restarts into it before you start work (press Skip for now if you are in a hurry). On a Mac, keep Locker Manager in your Applications folder. If your Mac has version 0.10.0 or older, install this version from this page once; after that it updates itself.

The version, build number and build date now show on the Home screen, along the bottom of the window and under the welcome screen, so you can always say exactly which version you have.

Also in this version: every change shows a message with Undo beside it; students can be added by hand without waiting for an import, and their year level and group changed; Move or swap shows both lockers first; a day's lock resets can be ticked off in one go and printed; a short welcome tour for first-time users; and a quick start for small schools that only record who has which locker.
