When two versions of the file meet, you can now keep the other version and add your own changes to it, choosing them one by one; any that no longer fit are named and skipped, and both versions are still kept as backups. On the History screen, Put back to before this… returns one student or locker to how it was, from the backup kept before the change. Scanning a label's optional QR code on a computer with the school's file open goes straight to that locker.
