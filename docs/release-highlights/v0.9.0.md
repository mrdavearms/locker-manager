When two versions of the file meet, you can now keep the other version and add your own changes to it, choosing them one by one; any that no longer fit are named and skipped, and both versions are still kept as backups. On the History screen, Put back to before this… returns one student or locker to how it was, from the backup kept before the change. Scanning a label's optional QR code on a computer with the school's file open goes straight to that locker. Also fixed: undo no longer fails after a code was shown for a new locker; codes are recorded before any file holding them is written; held-back letters come back under "changed" once their lock is sorted out; a code set made during the year is kept for next year; and the Changes report includes the whole first day. Settings now has a search box.
