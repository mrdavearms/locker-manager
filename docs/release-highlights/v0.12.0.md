This version makes Locker Manager safer to rely on. Nothing changes in how you use it day to day.

- **If your school's file will not open**, the first screen now has **Open a backup…**. It puts a backup in the file's place and keeps the damaged file as a backup too.
- **Changes are never lost quietly.** If the file cannot be saved when you close Locker Manager, it asks first: try again, close anyway (your changes are kept as a backup on this computer), or cancel. An update waits until your changes are saved. If Windows shuts down with the file open, your changes are saved or kept as a backup, and the next start tells you where.
- **No more waiting after a crash.** If Locker Manager stopped suddenly on your computer, you can carry on editing straight away instead of waiting 10 minutes.
- **Copies made by OneDrive** while two people edit at once are now found while the file is open, and the bottom bar says so.
- **Updates on Windows** no longer try again and again when they cannot install (for example on a computer where only IT may install programs). The new version is offered on the download page instead.
- **If Locker Manager cannot start**, it now shows a page saying why, instead of staying invisible, and it still fetches a fixed version.

**After this update:** once one computer has opened your school's file with this version, computers still on an older version open it read-only until they update. They update themselves the next time they start.

**Mac users on 0.11.0 to 0.11.3:** if updates show "ENOTEMPTY", install this version by hand once from the Mac download link above. From then on, updates install themselves.
